# Elevate Core logo

`elevate-core-logo-reference.png` is the original 1536 × 1536 artwork supplied by the owner on 2026-09-29.

The SVG variants reproduce that artwork as paths: the lettering is traced from the source, while the mint curves and circles are smoothed to remove raster artifacts. They share the same 940 × 560 viewBox and geometry. The light variant uses white lettering on navy backgrounds; the dark variant uses navy lettering on light backgrounds. Both use the site mint `#8DE9CF`.

Use these SVGs for the site. `npm run generate:brand-assets` renders the social card from the light SVG; it does not recreate or overwrite the vector artwork.
